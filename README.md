# みこぷらん 画数診断

会社名・屋号・ブランド名・商品名・ペット名・活動名・アプリ名などの総画数を計算し、81数理を参考にした、みこぷらん独自の診断データで数字の意味を表示する Web アプリです。

- HTML・CSS・JavaScript のみ（サーバー・APIキー・AI API・外部CDN 不要）
- `index.html` をダブルクリックしても動きます（このときは診断データの内蔵コピーを使用）
- GitHub ＋ Vercel でそのまま公開できます

---

## ファイル構成

```
index.html                     … アプリ本体（画面）
css/style.css                  … デザイン
js/stroke-calc.js              … 画数計算と CSV 読み込みのロジック（診断データとは分離）
js/app.js                      … 画面の動き（診断・比較・吉数候補・コピー・共有）
data/mikoplan_81_kakusu.csv    … ★ 診断データ（管理者が編集するファイル）
data/kakusu-fallback.js        … 上の CSV の内蔵コピー（index.html を直接開いた時用・自動生成）
data/kanji-strokes.js          … 漢字画数辞書（KANJIDIC2 由来・自動生成）
data/kyujitai-map.js           … 新字体⇔旧字体の検証済み対応表（自動生成）
data/kana-strokes.js           … ひらがな・カタカナの画数ルール
data/latin-strokes.js          … 英字（アルファベット）の画数ルール
assets/                        … アプリアイコン（favicon・ホーム画面用）と椿の装飾
manifest.webmanifest           … ホーム画面に追加したときの名前・アイコン設定
tools/build_data.py            … データ生成スクリプト（開発者向け）
LICENSES.md                    … 出典・ライセンス一覧
```

## GitHub・Vercel への公開手順

### 1. GitHub にアップロード
1. https://github.com にログインし、右上の「＋」→「New repository」
2. Repository name に `mikoplan-kakusu` などを入力し、「Create repository」
3. 作成した画面の「uploading an existing file」をクリック
4. ZIP を解凍した **フォルダの中身**（index.html、css、js、data、assets など）をまとめてドラッグ＆ドロップ
   - フォルダごとではなく、index.html が一番上に来るようにしてください
5. 下の「Commit changes」をクリック

### 2. Vercel で公開
1. https://vercel.com に GitHub アカウントでログイン
2. 「Add New…」→「Project」→ 先ほどのリポジトリの「Import」
3. Framework Preset は「Other」のまま、Build Command・Output Directory は空欄のまま
4. 「Deploy」をクリック → 1分ほどで `https://（名前）.vercel.app` が発行されます

以後、GitHub のファイルを更新すると Vercel にも自動で反映されます。

## 81画の診断文章を変更する方法

診断データは `data/mikoplan_81_kakusu.csv` の1ファイルだけです。計算プログラムを触る必要はありません。

### CSV の決まり
- 1行目の見出し（`画数,星評価,キーワード,特徴,強み,注意点,活かし方,判定根拠`）は変更しない
- 画数は 1〜81 をすべて1行ずつ（重複・欠けがあると画面上部に警告が出て、その画数の診断は表示されません）
- 星評価は `0`・`1`・`2`・`3` のいずれか（アプリは CSV の値をそのまま表示します）
- 文章の中に半角カンマ「,」を入れたい場合は、その欄全体を `"` で囲む（全角の「、」なら囲む必要はありません）
- 文字コードは **UTF-8** で保存（Excel の場合は「CSV UTF-8（コンマ区切り）」を選ぶ）

### 手順（GitHub 上で直接編集する場合）
1. GitHub のリポジトリで `data/mikoplan_81_kakusu.csv` を開く
2. 右上の鉛筆マーク（Edit）で編集し、「Commit changes」
3. Vercel に自動反映されます（公開版は CSV を直接読み込みます）

### 確認方法
公開ページの「資料」画面 → 「診断データについて」に、読み込み件数と星ごとの件数、1〜81画の一覧が表示されます。

### index.html を直接開いて使う場合のみ
ファイルを直接開いたとき（`file://`）はブラウザの制限で CSV を読み込めないため、内蔵コピー `data/kakusu-fallback.js` を使います。CSV を編集したら、次のコマンドで内蔵コピーも作り直してください（Python 3 が必要）。

```
python3 tools/build_data.py --csv-only data/mikoplan_81_kakusu.csv
```

公開版（Vercel）だけで使う場合は、この作業は不要です。

## 英字の画数を変更する方法

`data/latin-strokes.js` の数字を書き換えるだけで変わります（例：`"J":1` を `"J":2` に）。ひらがな・カタカナは `data/kana-strokes.js` で同じように変更できます。

## 採用した計算ルール（要点）

| 対象 | ルール |
|---|---|
| 漢字（新字体・標準） | KANJIDIC2 の画数。旧字体が入力されたら、検証済み対応表にある字だけ新字体で計算 |
| 漢字（旧字体） | 検証済み対応表（307組）と互換漢字（67字）だけ旧字体で計算。表にない字は推測変換しない |
| 旧字体が確認できない字 | 敎・淸 など画数データがない22組、意味で旧字体が変わる10字は「確認できません」 |
| 部首の原字換算 | 採用しない（氵＝4画などは流派により異なるため） |
| ひらがな | 伝統的な姓名判断で使われる画数表（例：な5・ね4・る3）。流派差あり |
| カタカナ | 教科書体の画数。半角カナは全角に正規化 |
| 濁点・半濁点 | ゛＝+2画、゜＝+1画 |
| 小さい字 | 元の字と同じ画数 |
| 長音符「ー」 | 1画 |
| 々 | 直前の漢字と同じ画数 |
| 英字 | みこぷらん採用ルール：ブロック体で直線・曲線のまとまりごとに1画（例：A3・L2・O1）。大文字・小文字は入力どおり |
| 数字・記号 | 計算しない（総画数を出さない） |
| スペース | 数えない |
| 辞書にない文字 | 0画にせず「この文字の画数は確認できません」、総画数・診断を出さない |
| 81画超 | 実際の総画数を表示し「評価対象外」。換算しない |

アプリ内の「ルール」画面にも同じ内容を掲載しています。

## 品質確認の結果

iPhone 13 相当の画面（Chromium）で自動テストを行い、すべて合格しています。

- 81件のデータ読み込み（星3：21件・星2：15件・星1：13件・星0：32件）
- 星0（☆☆☆）〜星3 の表示
- 画数合計（例：椿13＋星9＋命8＋術11＝41画）
- 新字体・旧字体の切り替えと再計算（例：国学院 26画 → 國學院 37画）
- 英字の計算（ABC＝7画、Tsubaki Seimei＝24画、全角ＡＢＣも同じ）
- 未対応文字（数字・記号・アクセント付き英字・辞書外の漢字・単独の々）で総画数を出さない
- 81画超（87画）で評価対象外を表示
- 名前比較（3件、未対応文字を含む候補も正しく表示）
- 吉数候補（直前の診断値を自動入力）
- コピー、共有機能がない環境でのコピー切り替え
- 横スクロールなし、コンソールエラーなし
- `index.html` 直接起動で動作、CSV の日本語の文字化けなし

※ 実機の iPhone Safari での確認は、公開後に一度お試しください（使用している機能はすべて iOS 14 以降の Safari が対応しているものです）。
